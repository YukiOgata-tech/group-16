# タクトスイッチ制御機能

## 概要

`real_line_follower_with_button.py` は、タクトスイッチで走行/停止の制御とシャットダウンができる実機用プログラムです。

## 操作方法

| 操作 | 動作 |
|------|------|
| **短押し（1秒未満）** | 走行/停止の切り替え |
| **長押し（3秒以上）** | システムシャットダウン |
| **Ctrl+C** | プログラム終了 |

## ハードウェア構成

### 追加部品

| 部品 | 数量 | 接続先 |
|------|------|--------|
| タクトスイッチ | 1 | GPIO 3 |
| LED（オプション） | 1 | GPIO 23 |
| 抵抗 10kΩ | 1 | プルアップ用 |

### 配線図

```
Raspberry Pi
  ┌─────────────────┐
  │  GPIO 3         │──┬── タクトスイッチ ── GND
  │                 │  │
  │                 │  └── 10kΩ ── 3.3V (プルアップ)
  │                 │
  │  GPIO 23 ───────│──── LED ── 抵抗 330Ω ── GND
  │                 │     (ステータス表示用・オプション)
  └─────────────────┘
```

### ピン設定

```python
PIN_BUTTON = 3   # タクトスイッチ
PIN_LED = 23     # ステータスLED（オプション）
```

```

  ↓

  ↓
```

```
  ↓
システムシャットダウン
```

## プログラムの仕組み

### 状態管理

```python
class RunningState:
    def __init__(self):
        self.is_running = False  # 走行中かどうか

    def toggle(self):
        """走行/停止を切り替える"""
        self.is_running = not self.is_running
        if self.is_running:
            print(">>> 走行開始")
            # LED点灯
        else:
            print(">>> 一時停止")
            # モーター停止、LED消灯
```

### ボタンコールバック

```python
# 短押し: 走行/停止切り替え
button.when_pressed = lambda: on_button_pressed(state)

# 長押し（3秒）: シャットダウン
button.when_held = on_button_held
```

### 制御ループ

```python
def line_follow():
    while True:
        if state.is_running:
            # 走行中: 制御計算
            left, right = controller.prs2mtrs()
            yield (left, right)
        else:
            # 停止中: モーター停止
            yield (0, 0)
```

## LEDステータス表示（オプション）

ステータスLEDを追加すると、現在の状態が視覚的にわかります。

| LED状態 | 意味 |
|---------|------|
| **点灯** | 走行中 |
| **消灯** | 停止中 |

### LED配線

```
GPIO 23 ── LED ── 抵抗 330Ω ── GND
           (アノード)  (カソード)
```

LEDがない場合でも、プログラムは正常に動作します（LED初期化をスキップ）。

## トラブルシューティング

### 問題1: ボタンが反応しない

**確認項目**:
- [ ] タクトスイッチがGPIO 3に接続されているか
- [ ] プルアップ抵抗（10kΩ）が接続されているか
- [ ] GNDに正しく接続されているか

**対策**:
```bash
# GPIO状態確認
gpio readall
```

### 問題2: ボタンを押すと即座にシャットダウンする

**原因**: 短押しと長押しの判定時間が短すぎる

**対策**:
```python
# real_line_follower_with_button.py:185 を変更
button = Button(PIN_BUTTON, hold_time=5)  # 3 → 5秒に延長
```

### 問題3: LEDが点灯しない

**確認項目**:
- [ ] LEDの極性が正しいか（アノード→GPIO、カソード→GND）
- [ ] 抵抗値が適切か（330Ω推奨）
- [ ] GPIO 23に接続されているか

**対策**:
```bash
# LED単独テスト
python3 -c "from gpiozero import LED; from time import sleep; led = LED(23); led.on(); sleep(2); led.off()"
```

### 問題4: ボタンが誤動作する（チャタリング）

**原因**: 機械的なスイッチのバウンスノイズ

**対策**:
```python
# gpiozeroのbounce_time パラメータを追加
button = Button(PIN_BUTTON, hold_time=3, bounce_time=0.1)
```

## 応用例


## 比較: ボタンありとボタンなし

| 機能 | ボタンなし | ボタンあり |
|------|-----------|-----------|
| 起動後の動作 | 即座に走行開始 | 停止状態で待機 |
| 一時停止 | Ctrl+C のみ | ボタン短押し |
| シャットダウン | SSH接続が必要 | ボタン長押し |
| モニターレス運用 | 不便 | 容易 |
